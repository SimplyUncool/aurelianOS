# Decision 0001: Desktop Architecture

## Decision

aurelianOS will use its own desktop shell rather than GNOME or KDE as its
primary desktop environment.

## Requirements

- Wayland-first
- Conventional desktop workflow
- Optional tiling
- Multi-monitor support
- Fractional scaling
- HDR and VRR
- Graphical system administration
- Advanced Linux access

## Alternatives considered

- GNOME
- KDE Plasma
- COSMIC
- Hyprland
- Custom shell
