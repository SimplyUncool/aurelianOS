# aurelianOS

A Linux-based operating system for PCs focused on simplicity, performance, control, and Windows application compatibility.

## Status

aurelianOS is currently in early development.

The current build is a minimal x86_64 Linux system built with Buildroot and capable of booting in QEMU.

## Goals

- Polished and consistent desktop experience
- Simple graphical system configuration
- Full Linux environment for advanced users
- Broad Windows application compatibility
- Gaming support
- Automatic hardware configuration
- Unified application management
- Reliable system updates
- System recovery and rollback
- Performance without unnecessary system overhead

## Philosophy

aurelianOS aims to make Linux accessible without hiding it.

Normal users should be able to use the operating system through the graphical interface without needing Linux knowledge.

Advanced users should have access to the underlying Linux environment, including the terminal, filesystem, services, and development tools.

## Development

aurelianOS is currently being developed for x86_64 PCs.

The project uses:

- Linux
- Buildroot
- QEMU
